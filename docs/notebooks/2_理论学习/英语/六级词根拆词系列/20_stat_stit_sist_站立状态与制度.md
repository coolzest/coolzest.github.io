# 20 stat / stit / sist：站立、状态与制度

## 核心词根

- <span style="color:#dc2626;font-weight:700">stat / st</span>：站立，状态。
- <span style="color:#dc2626;font-weight:700">stit</span>：建立，放置。
- <span style="color:#dc2626;font-weight:700">sist</span>：站住，坚持。

## 词义延伸主线

`stat` 是站住形成状态，稳定就是站得住，建立就是让它站起来。`stit` 是放置建立，所以 constitute 是放在一起构成整体。`sist` 是站住，坚持是站在观点里，抵抗是站回去挡住。
