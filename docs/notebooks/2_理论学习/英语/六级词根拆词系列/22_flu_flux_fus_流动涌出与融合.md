# 22 flu / flux / fus：流动、涌出与融合

## 核心词根

- <span style="color:#dc2626;font-weight:700">flu / flux</span>：流动。
- <span style="color:#dc2626;font-weight:700">fus</span>：倒出，融合。

## 词义延伸主线

`flu` 是流动，语言像水流就是 fluent，影响流进别人就是 influence，价格像水波就是 fluctuate。`fus` 是倒出和融合，倒在一起是 fusion，倒得分不清是 confusion，往四处倒是 diffusion。
