# 03 数据与特征

> 模型不是凭空变聪明。它能学到什么，首先取决于你给了它什么数据，以及这些数据被怎样表达。

## 一句话

数据是例子，特征是描述例子的字段，标签是我们希望模型学会预测的答案。

```text
样本：一套房子
特征：面积、位置、楼层、年份
标签：真实成交价
```

## 样本、特征、标签

| 名称 | 简单理解 | 房价预测例子 |
| --- | --- | --- |
| 样本 | 一条训练记录 | 某一套房 |
| 特征 | 输入字段 | 面积、城市、楼层 |
| 标签 | 正确答案 | 成交价 |

表格形式：

| 面积 | 城市 | 楼层 | 年份 | 成交价 |
| --- | --- | --- | --- | --- |
| 89 | 杭州 | 12 | 2018 | 320 万 |
| 120 | 上海 | 8 | 2015 | 760 万 |

前四列是特征，最后一列是标签。

## 特征为什么重要

模型只能从输入里找规律。没有给它关键特征，它很难猜出来。

```text
只给面积 -> 只能学到面积和价格的大概关系
给面积 + 城市 + 地段 + 年份 -> 能学到更接近真实的规律
```

特征不是越多越好。无关特征会制造噪声，错误特征会误导模型。

## 数据要变成数字

模型通常更擅长处理数字，所以文字、类别、图片都需要转换。

| 原始数据 | 转换方式 |
| --- | --- |
| 城市：北京/上海/杭州 | 编码成类别数字或 one-hot |
| 文本评论 | 分词、向量化、嵌入表示 |
| 图片 | 像素矩阵或视觉特征 |
| 日期 | 年、月、星期、是否节假日 |

简单理解：特征工程就是把现实世界的信息翻译成模型能理解的形式。

## 常见数据处理

| 处理 | 为什么做 |
| --- | --- |
| 去重 | 防止同一条数据重复影响模型 |
| 补缺失 | 让模型能处理空值 |
| 处理异常值 | 避免极端错误数据带偏模型 |
| 标准化 | 让不同量纲的数值更容易训练 |
| 编码类别 | 把文字类别转成数字 |
| 划分数据集 | 检验模型是否真的学会规律 |

```text
原始数据
  ↓
清洗
  ↓
特征转换
  ↓
训练集 / 验证集 / 测试集
```

## 数据划分

不能把所有数据都拿来训练，否则不知道模型对新数据表现如何。

```text
全部数据
├── 训练集：学习规律
├── 验证集：调参选模型
└── 测试集：最后验收
```

常见比例是 8:1:1 或 7:2:1，不是固定规则，要看数据量和任务。

## 数据泄露

数据泄露是入门时最容易忽略的问题：模型在训练时看到了本不该知道的信息。

例子：

| 场景 | 为什么泄露 |
| --- | --- |
| 预测用户是否流失，却使用“注销时间”作为特征 | 这个字段在预测时还不知道 |
| 随机划分同一用户的多条记录到训练集和测试集 | 模型可能记住用户特征 |
| 用全量数据先标准化，再切训练集和测试集 | 测试集信息提前参与处理 |

数据泄露会让评估结果虚高，上线后效果突然变差。

## 好数据的样子

| 标准 | 解释 |
| --- | --- |
| 准确 | 标签和字段尽量真实 |
| 相关 | 特征和任务有关系 |
| 覆盖 | 包含足够多的场景 |
| 平衡 | 不被某一类样本严重支配 |
| 及时 | 数据分布接近当前真实环境 |

## 小结

- 样本是例子，特征是输入，标签是答案。
- 模型只能从给定特征里学习。
- 数据清洗和特征工程常常比换模型更重要。
- 训练集、验证集、测试集要分开使用。
- 数据泄露会让模型看起来很好，实际很差。
