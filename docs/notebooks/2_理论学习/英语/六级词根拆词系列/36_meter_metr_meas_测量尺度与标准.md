# 36 meter / metr / meas：测量、尺度与标准

## 核心词根

- <span style="color:#dc2626;font-weight:700">meter / metr / meas</span>：测量。

## meter / metr：测量

| 单词 | 彩色拆词 | 构词逻辑 | 六级常用义 |
| --- | --- | --- | --- |
| meter | <span style="color:#dc2626;font-weight:700">meter</span> | 用来测量的单位或仪器 | 米；仪表 |
| thermometer | <span style="color:#7c3aed;font-weight:700">thermo</span> + <span style="color:#dc2626;font-weight:700">meter</span> | `thermo` 热 + 测量 | 温度计 |
| barometer | <span style="color:#7c3aed;font-weight:700">baro</span> + <span style="color:#dc2626;font-weight:700">meter</span> | `baro` 压力 + 测量 | 气压计；指标 |
| diameter | <span style="color:#2563eb;font-weight:700">dia</span> + <span style="color:#dc2626;font-weight:700">meter</span> | 穿过圆心测量 | 直径 |
| geometry | <span style="color:#7c3aed;font-weight:700">geo</span> + <span style="color:#dc2626;font-weight:700">metry</span> | 土地 + 测量，后指空间图形学 | 几何学 |
| symmetry | <span style="color:#2563eb;font-weight:700">sym</span> + <span style="color:#dc2626;font-weight:700">metry</span> | 一起测量，两边相称 | 对称 |
| asymmetric | <span style="color:#2563eb;font-weight:700">a</span> + <span style="color:#2563eb;font-weight:700">sym</span> + <span style="color:#dc2626;font-weight:700">metr</span> + <span style="color:#16a34a;font-weight:700">-ic</span> | 不对称测量 | 不对称的 |
| parameter | <span style="color:#dc2626;font-weight:700">para</span> + <span style="color:#7c3aed;font-weight:700">meter</span> | 在旁边限定测量范围的量 | 参数，限制因素 |

## meas：测量

| 单词 | 彩色拆词 | 构词逻辑 | 六级常用义 |
| --- | --- | --- | --- |
| measure | <span style="color:#dc2626;font-weight:700">meas</span> + <span style="color:#16a34a;font-weight:700">-ure</span> | 测出来的尺度，也指措施 | 测量；措施 |
| measurement | <span style="color:#dc2626;font-weight:700">meas</span> + <span style="color:#16a34a;font-weight:700">-urement</span> | 测量结果或过程 | 测量，尺寸 |
| measurable | <span style="color:#dc2626;font-weight:700">meas</span> + <span style="color:#16a34a;font-weight:700">-urable</span> | 能被测量的 | 可衡量的 |
| immeasurable | <span style="color:#2563eb;font-weight:700">im</span> + <span style="color:#dc2626;font-weight:700">meas</span> + <span style="color:#16a34a;font-weight:700">-urable</span> | 无法测量的 | 不可估量的 |
| moderate | <span style="color:#7c3aed;font-weight:700">mod</span> + <span style="color:#16a34a;font-weight:700">-erate</span> | `mod` 尺度、方式：保持在合适尺度内 | 适度的；缓和 |
| dimension | <span style="color:#2563eb;font-weight:700">di</span> + <span style="color:#7c3aed;font-weight:700">mens</span> + <span style="color:#16a34a;font-weight:700">-ion</span> | 测量出的方向和范围 | 维度，尺寸 |

## 词义延伸主线

`meter / metr / meas` 都是“测量”。测热是 thermometer，测压力是 barometer，穿过圆测是 diameter；measure 既是测量，也是“经过衡量后采取的措施”。
