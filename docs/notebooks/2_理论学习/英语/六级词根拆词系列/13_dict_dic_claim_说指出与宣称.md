# 13 dict / dic / claim：说、指出与宣称

## 核心词根

- <span style="color:#dc2626;font-weight:700">dict / dic</span>：说，指出，宣告。
- <span style="color:#dc2626;font-weight:700">claim / clam</span>：喊叫，宣称，要求。

## 词义延伸主线

`dict / dic` 的核心是“说出判断”：提前说是预测，反着说是矛盾，指出含义是 indicate。`claim` 带有“喊出来争取”的感觉：喊自己有权利是要求，公开喊是宣布，重新喊回来是收回。
