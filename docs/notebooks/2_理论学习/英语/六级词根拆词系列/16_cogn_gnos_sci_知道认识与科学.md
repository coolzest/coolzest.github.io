# 16 cogn / gnos / sci：知道、认识与科学

## 核心词根

- <span style="color:#dc2626;font-weight:700">cogn</span>：知道，认识。
- <span style="color:#dc2626;font-weight:700">gnos</span>：知道，判断。
- <span style="color:#dc2626;font-weight:700">sci</span>：知道，知识。

## 词义延伸主线

`cogn` 是认识，所以 re-cognize 是再次认出；`gnos` 是判断，所以 dia-gnosis 是穿透表象判断病因；`sci` 是知识，science 是系统知识，conscious 是“自己知道自己在做什么”。
