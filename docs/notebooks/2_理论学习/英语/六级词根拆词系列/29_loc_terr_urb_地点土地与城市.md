# 29 loc / terr / urb：地点、土地与城市

## 核心词根

- <span style="color:#dc2626;font-weight:700">loc</span>：地方，位置。
- <span style="color:#dc2626;font-weight:700">terr</span>：土地，地球。
- <span style="color:#dc2626;font-weight:700">urb</span>：城市。

## 词义延伸主线

`loc` 是位置，分配就是把资源放到位置上；`terr` 是土地，territory 是领土，terrain 是地形；`urb` 是城市，urbanization 是城市化，suburb 是城市边缘区域。
