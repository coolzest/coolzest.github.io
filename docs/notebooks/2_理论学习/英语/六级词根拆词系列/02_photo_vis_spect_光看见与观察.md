# 02 photo / vis / spect：光、看见与观察

## 核心词根

- <span style="color:#dc2626;font-weight:700">photo</span>：光。`photosynthesis` 里 `photo` 是光，`synthesis` 是合成，所以是“光合作用”。
- <span style="color:#dc2626;font-weight:700">vis / vid</span>：看见。视觉、证据、监督都和“看见”有关。
- <span style="color:#dc2626;font-weight:700">spect</span>：看、观察。更强调“有意识地看、审视”。

## 词义延伸主线

`photo` 是光，光可以记录，所以有照片；`vis / vid` 是看见，看见的东西可以成为证据；`spect` 是主动观察，向前看是前景，换角度看是观点，回头看是回顾，往里面看是检查。
