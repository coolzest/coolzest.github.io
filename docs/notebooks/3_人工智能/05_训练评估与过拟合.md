# 05 训练评估与过拟合

> 模型训练不是“看一次数据就懂了”，而是一次次预测、犯错、修正。问题是：修正到什么程度才刚刚好？

## 一句话

训练是让损失变小，评估是看模型在新数据上是否仍然好，过拟合是模型把训练集背熟了却不会举一反三。

```mermaid
flowchart LR
    A[输入数据] --> B[模型预测]
    B --> C[计算损失]
    C --> D[调整参数]
    D --> B
```

## 损失函数

损失函数用来衡量模型错得有多离谱。

```text
预测值：320
真实值：300
误差：20
```

回归任务常用 MSE：

```text
MSE = 平均((预测值 - 真实值)^2)
```

分类任务常用交叉熵。入门阶段先不用急着推公式，只要记住：损失越小，说明模型在训练数据上越接近答案。

## 梯度下降

梯度下降可以理解为“顺着下坡方向调参数”。

```text
损失
 ^
 |        *
 |      *
 |    *
 |  *
 |*
 +----------------> 参数
```

模型不知道最优参数在哪里，只能根据当前错误一点点调整。

```text
当前参数 -> 算损失 -> 找下降方向 -> 小步更新 -> 再算损失
```

这一步的“小步”叫学习率。

## 学习率

| 学习率 | 可能结果 |
| --- | --- |
| 太大 | 一步跨太远，来回震荡，甚至训练失败 |
| 太小 | 走得太慢，训练时间很长 |
| 合适 | 稳定下降 |

```text
太大：一步跳过最低点
太小：慢慢挪
合适：比较顺地往低处走
```

## 过拟合和欠拟合

| 情况 | 表现 | 类比 |
| --- | --- | --- |
| 欠拟合 | 训练集和测试集都差 | 没学会 |
| 正常拟合 | 训练集好，测试集也好 | 真理解了 |
| 过拟合 | 训练集很好，测试集变差 | 背题，不会新题 |

图像化：

```text
欠拟合：线太简单，抓不住规律
正常：抓住主要趋势
过拟合：线弯来弯去，把噪声也记住
```

## 怎么发现过拟合

看训练集和验证集表现：

```text
训练损失持续下降
验证损失先下降后上升
=> 可能过拟合
```

```text
损失
 ^
 | 验证集      __/
 |          __/
 | 训练集 __/
 +----------------> 训练轮数
```

训练集越来越好，验证集越来越差，就是危险信号。

## 怎么缓解过拟合

| 方法 | 直觉 |
| --- | --- |
| 增加数据 | 见更多例子，不容易背题 |
| 简化模型 | 模型没那么容易记噪声 |
| 正则化 | 惩罚过于复杂的参数 |
| 早停 | 验证集变差时停止训练 |
| 数据增强 | 对图片、文本等做合理变化 |
| 交叉验证 | 更稳定地估计模型效果 |

没有一种方法永远最好。先看问题在哪里，再选方法。

## 评估要贴近真实场景

模型评估不能只看一个数字。

要问：

- 测试数据是否接近真实使用场景？
- 错误样本集中在哪些人群或场景？
- 误报和漏报哪个代价更高？
- 模型速度是否满足要求？
- 数据变化后模型是否会失效？

## 小结

- 损失函数衡量模型错得多大。
- 训练就是调整参数，让损失下降。
- 学习率决定每次参数更新的步子。
- 欠拟合是没学会，过拟合是背过头。
- 评估要看新数据表现，而不是只看训练集。
