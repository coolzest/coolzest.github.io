# 04 tract / duc / mit：拉、引导与发送

## 核心词根

- <span style="color:#dc2626;font-weight:700">tract</span>：拉。
- <span style="color:#dc2626;font-weight:700">duc / duct</span>：引导，带领。
- <span style="color:#dc2626;font-weight:700">mit / miss</span>：发送，放出。

## 词义延伸主线

被拉过来是吸引，被拉散是分心，被拉出来是提取；被引导进去是介绍，被引出结果是生产，被往回引是减少；被送出去是排放，送上去是提交，完全送进去就是承诺或投入。
