# 06 form / struct / fac：形状、结构与制造

## 核心词根

- <span style="color:#dc2626;font-weight:700">form</span>：形状，形成。
- <span style="color:#dc2626;font-weight:700">struct</span>：建造，结构。
- <span style="color:#dc2626;font-weight:700">fac / fact / fect / fic</span>：做，制造。

## 词义延伸主线

`form` 是形状和形成，所以通知是让认识成形，改革是重新成形，转型是变成另一种形状。`struct` 是搭结构，建造、指导、基础设施都围绕“搭起来”。`fac` 是做，做出来的结果是 effect，能做出结果的是 effective，做得省力的是 efficient。
