# 17 cap / cept / tain：抓住、接受与保持

## 核心词根

- <span style="color:#dc2626;font-weight:700">cap / capt / cept</span>：抓，拿，接收。
- <span style="color:#dc2626;font-weight:700">tain / ten</span>：握住，保持。

## 词义延伸主线

`cept` 是“接住”：往自己这边接是 accept，从整体拿出去是 except，中间抓住是 intercept。`tain` 是“握住”：握在里面是 contain，一直握住状态是 maintain，从下面托住持续是 sustain，抓到目标是 attain。
