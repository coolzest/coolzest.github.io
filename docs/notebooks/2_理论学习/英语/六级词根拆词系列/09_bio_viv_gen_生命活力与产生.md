# 09 bio / viv / gen：生命、活力与产生

## 核心词根

- <span style="color:#dc2626;font-weight:700">bio</span>：生命。
- <span style="color:#dc2626;font-weight:700">viv / vit</span>：活，生命力。
- <span style="color:#dc2626;font-weight:700">gen</span>：产生，出生，种类。

## 词义延伸主线

`bio` 是生命本体，`viv / vit` 是活着的状态和活力，`gen` 是生命或事物的产生。生命被系统研究是 biology，生命被记录是 biography，重新活是 revive，活过灾难是 survive，产生能量的是 generator，一代人是 generation。
