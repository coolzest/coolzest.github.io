# 23 pel / puls / driv：推动、驱赶与冲动

## 核心词根

- <span style="color:#dc2626;font-weight:700">pel / puls</span>：推，驱赶。
- <span style="color:#dc2626;font-weight:700">driv</span>：驱动，驾驶。

## 词义延伸主线

`pel / puls` 是推：往外推是 expel，往回推是 repel，向前推是 propel，推得你不得不做是 compel。内心推出来的一下是 impulse，必须被推着做的是 compulsory。
