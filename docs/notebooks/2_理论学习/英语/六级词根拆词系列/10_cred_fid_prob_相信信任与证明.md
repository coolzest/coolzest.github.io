# 10 cred / fid / prob：相信、信任与证明

## 核心词根

- <span style="color:#dc2626;font-weight:700">cred</span>：相信。
- <span style="color:#dc2626;font-weight:700">fid</span>：信任。
- <span style="color:#dc2626;font-weight:700">prob / prov</span>：测试，证明。

## 词义延伸主线

`cred` 是别人是否相信你，所以有信用、可信度、资历；`fid` 是信任关系，往里走是信心，基于信任的是机密；`prob / prov` 是证明和测试，证明后认可就是 approve，还在测试中就是 probation，看起来能被证明为真就是 probable。
