# 六级单词词根记忆

> 这套笔记只做一件事：把六级词汇拆开，看清每个前缀、词根、后缀为什么会推出这个词义。

## 颜色约定

- <span style="color:#2563eb;font-weight:700">蓝色</span>：前缀、方向、位置、关系。
- <span style="color:#dc2626;font-weight:700">红色</span>：本篇核心词根。
- <span style="color:#7c3aed;font-weight:700">紫色</span>：另一个实义词根，常和核心词根组合。
- <span style="color:#16a34a;font-weight:700">绿色</span>：后缀，决定词性或抽象意义。
- <span style="color:#ea580c;font-weight:700">橙色</span>：连接音、变体、容易忽略的小部件。

## 记忆方法

不要把词根当成死板公式，而要当成“意思的方向盘”。

比如 `photography`：

<span style="color:#2563eb;font-weight:700">photo</span> 表示“光”，这个意思也出现在 `photosynthesis` 光合作用里；<span style="color:#dc2626;font-weight:700">graph</span> 表示“写、画、记录”；<span style="color:#16a34a;font-weight:700">-y</span> 表示“行为、技艺、学科”。所以 `photography` 不是硬背“摄影”，而是“用光来记录的行为”，自然就是摄影。

先看“核心词根”，再看每个表格里的彩色拆词。一个单词如果有两个词根，两个都会解释，不会只讲一个然后把另一个丢给你猜。
