# 15 sens / sent / path：感觉、情绪与同情

## 核心词根

- <span style="color:#dc2626;font-weight:700">sens / sent</span>：感觉，感知。
- <span style="color:#dc2626;font-weight:700">path</span>：感情，痛苦。

| sense | <span style="color:#dc2626;font-weight:700">sens</span> + <span style="color:#16a34a;font-weight:700">-e</span> | 感觉到的意义 | 感觉；意义；理智 |
| sensible | <span style="color:#dc2626;font-weight:700">sens</span> + <span style="color:#16a34a;font-weight:700">-ible</span> | 能感觉并判断得合理 | 明智的，合理的 |
| sensitive | <span style="color:#dc2626;font-weight:700">sens</span> + <span style="color:#16a34a;font-weight:700">-itive</span> | 容易感觉到刺激的 | 敏感的 |

## path：感情，痛苦

| 单词 | 彩色拆词 | 构词逻辑 | 六级常用义 |
| --- | --- | --- | --- |

| sympathetic | <span style="color:#2563eb;font-weight:700">sym</span> + <span style="color:#dc2626;font-weight:700">path</span> + <span style="color:#16a34a;font-weight:700">-etic</span> | 能共同感受的 | 同情的；支持的 |

## 词义延伸主线

`sens` 是感知：有 sense 才能 sensible，太容易感觉刺激就是 sensitive，多人感觉一致就是 consensus。`path` 是痛苦和感情：一起感受是 sympathy，进入感受是 empathy，没有感受是 apathy。
