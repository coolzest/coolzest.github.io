# 25 soci / commun / civ：社会、共同体与公民

## 核心词根

- <span style="color:#dc2626;font-weight:700">soci</span>：同伴，社会。
- <span style="color:#dc2626;font-weight:700">commun</span>：共同，交流。
- <span style="color:#dc2626;font-weight:700">civ</span>：城市，公民，文明。

## 词义延伸主线

`soci` 是同伴和社会，联系起来是 associate；`commun` 是共同，信息变成共同拥有就是 communicate；`civ` 是城市公民生活，发展成文明 civilization，也指公民 civic。
