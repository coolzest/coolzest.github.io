# 19 pend / pens / pond：悬挂、称量与花费

## 核心词根

- <span style="color:#dc2626;font-weight:700">pend</span>：悬挂，挂着。
- <span style="color:#dc2626;font-weight:700">pens</span>：称量，支付，补偿。
- <span style="color:#dc2626;font-weight:700">pond</span>：称重，回应。

## 词义延伸主线

`pend` 是挂着，所以依赖是挂在别人身上，暂停是事情悬起来。`pens` 是称量支付，所以 expense 是付出去的钱，compensate 是称量后补回来。`pond` 是回应，所以 respond 是反应，responsible 是能回应、能承担。
