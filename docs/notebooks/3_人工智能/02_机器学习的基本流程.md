# 02 机器学习的基本流程

> 机器学习不是一上来就选模型。真正的起点是：我要解决什么问题，输入是什么，输出是什么，怎么判断做得好。

## 一句话

机器学习流程就是：定义问题，准备数据，选择模型，训练模型，评估效果，然后上线迭代。

```mermaid
flowchart LR
    A[定义问题] --> B[收集数据]
    B --> C[处理数据]
    C --> D[选择模型]
    D --> E[训练]
    E --> F[评估]
    F --> G[上线]
    G --> H[反馈迭代]
```

## 第一步：定义问题

不要先问“用什么算法”，先问这三件事：

| 问题 | 例子 |
| --- | --- |
| 输入是什么 | 用户年龄、点击记录、商品信息 |
| 输出是什么 | 是否购买、预测价格、推荐列表 |
| 好坏怎么衡量 | 准确率、误差大小、点击率、召回率 |

如果输出是一个数值，多半是回归。  
如果输出是几个类别之一，多半是分类。

## 第二步：准备数据

模型从数据中学习，数据就像教材。教材错了，学生很难学好。

```text
原始数据
  ↓
清洗缺失值、异常值、重复值
  ↓
转成模型能读的数字
  ↓
划分训练集、验证集、测试集
```

常见数据问题：

| 问题 | 影响 |
| --- | --- |
| 缺失值 | 模型不知道该怎么处理空白 |
| 异常值 | 少数极端值把规律带偏 |
| 标签错误 | 模型学到错误答案 |
| 数据太少 | 模型很难总结稳定规律 |
| 样本不均衡 | 模型偏向数量多的类别 |

## 第三步：选择模型

入门阶段可以先这样选：

| 任务 | 可以先试的模型 |
| --- | --- |
| 预测数值 | 线性回归、决策树、随机森林 |
| 判断类别 | 逻辑回归、决策树、朴素贝叶斯 |
| 图片、语音、文本 | 神经网络、预训练模型 |
| 生成文本 | 大语言模型 |

简单模型不是低级。简单模型好解释、快、容易发现问题，常常是很好的起点。

## 第四步：训练模型

训练可以理解为“不断改参数，让错误变小”。

```text
模型做预测
  ↓
和标准答案比较
  ↓
算出错误有多大
  ↓
调整参数
  ↓
重复很多次
```

机器学习里经常说的“损失函数”，就是用来衡量错误大小的函数。

## 第五步：评估模型

训练集表现好，不代表真的好。模型可能只是把练习题背下来了。

```text
训练集：给模型学习用
验证集：调参数、选模型用
测试集：最后验收用
```

类比考试：

| 数据集 | 类比 |
| --- | --- |
| 训练集 | 平时练习题 |
| 验证集 | 模拟考试 |
| 测试集 | 最终考试 |

## 第六步：上线和迭代

模型上线后还要继续观察：

- 新数据分布是否变了。
- 用户行为是否变了。
- 错误案例集中在哪里。
- 模型速度和成本是否能接受。
- 是否出现偏见、泄露、滥用风险。

模型不是训练完就结束，而是持续维护的系统。

## 一个完整例子

以“预测房价”为例：

| 步骤 | 做什么 |
| --- | --- |
| 定义问题 | 根据房屋信息预测成交价 |
| 收集数据 | 面积、位置、楼层、建造年份、价格 |
| 处理数据 | 去掉明显错误价格，补全缺失字段 |
| 选择模型 | 先试线性回归，再试树模型 |
| 训练 | 用历史成交数据拟合规律 |
| 评估 | 看预测价和真实价相差多少 |
| 上线 | 给新房源输出估价，并持续校正 |

## 小结

- 机器学习项目从问题定义开始，不是从算法开始。
- 输入、输出、评价指标要先说清楚。
- 数据质量决定模型上限。
- 训练是让错误逐渐变小。
- 评估要看模型在没见过的数据上表现如何。
