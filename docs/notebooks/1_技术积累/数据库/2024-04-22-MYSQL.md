# MySQL 基础

这篇按“工作时忘了就来复制”的方式整理：前面是可编辑 SQL 代码框，后面才是必要解释。

## 可填空代码框

写笔记时，在代码块里用 `{{提示词}}` 标出要填的地方，网页会自动变成可输入的小框。复制时复制的是填好后的最终代码。

### 创建数据库

```sql
CREATE DATABASE IF NOT EXISTS `{{数据库名}}`
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

### 创建表

```sql
CREATE TABLE `{{表名}}` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT 'ID',
  `{{字段名}}` VARCHAR(50) NOT NULL COMMENT '名称',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

### 查询数据

```sql
SELECT {{字段列表}}
FROM `{{表名}}`
WHERE {{条件}};
```

### 插入数据

```sql
INSERT INTO `{{表名}}` ({{字段列表}})
VALUES ({{值列表}});
```

### 更新数据

```sql
UPDATE `{{表名}}`
SET {{字段 = 值}}
WHERE {{条件}};
```

### 删除数据

```sql
DELETE FROM `{{表名}}`
WHERE {{条件}};
```

### 创建索引

```sql
CREATE INDEX `{{索引名}}`
ON `{{表名}}` (`{{字段名}}`);
```

### 授权

```sql
GRANT SELECT, INSERT, UPDATE
ON `{{数据库名}}`.*
TO '{{用户名}}'@'{{主机}}';
```

## SQL 分类

| 分类 | 作用 | 常用关键字 |
| --- | --- | --- |
| DDL | 定义库、表、字段 | `CREATE`, `ALTER`, `DROP`, `TRUNCATE` |
| DML | 增删改数据 | `INSERT`, `UPDATE`, `DELETE` |
| DQL | 查询数据 | `SELECT` |
| DCL | 管理用户和权限 | `CREATE USER`, `GRANT`, `REVOKE` |
| TCL | 控制事务 | `COMMIT`, `ROLLBACK` |

建议：关键字大写，库名、表名、字段名保持项目内统一。

## 数据库操作 { #数据库操作 }

### 查看所有数据库

```sql
SHOW DATABASES;
```

### 查看当前数据库

```sql
SELECT DATABASE();
```

### 创建数据库

```sql
CREATE DATABASE IF NOT EXISTS `blog`
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

### 选择数据库

```sql
USE `blog`;
```

### 删除数据库

```sql
DROP DATABASE IF EXISTS `blog`;
```

`utf8mb4` 比 `utf8` 更完整，能存 emoji 和更多特殊字符。新建业务库优先用 `utf8mb4`。

## 表操作 { #表操作 }

### 查看当前库的所有表

```sql
SHOW TABLES;
```

### 查看表结构

```sql
DESC `user`;
```

### 查看建表语句

```sql
SHOW CREATE TABLE `user`;
```

### 创建表

```sql
CREATE TABLE `user` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
  `username` VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
  `age` INT CHECK (`age` >= 0 AND `age` <= 120),
  `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态：1启用，0禁用',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
) COMMENT '用户表';
```

### 添加字段

```sql
ALTER TABLE `user` ADD `email` VARCHAR(100) COMMENT '邮箱';
```

### 修改字段类型

```sql
ALTER TABLE `user` MODIFY `email` VARCHAR(150);
```

### 修改字段名和类型

```sql
ALTER TABLE `user` CHANGE `email` `user_email` VARCHAR(150);
```

### 删除字段

```sql
ALTER TABLE `user` DROP `user_email`;
```

### 修改表名

```sql
ALTER TABLE `user` RENAME TO `app_user`;
```

### 删除表

```sql
DROP TABLE IF EXISTS `app_user`;
```

### 清空表

```sql
TRUNCATE TABLE `app_user`;
```

`TRUNCATE` 是清空整张表，不能加 `WHERE`。只想删除部分数据时用 `DELETE`。

## 数据类型

### 数值类型

| 类型 | 用途 |
| --- | --- |
| `TINYINT` | 状态、类型、布尔值 |
| `INT` | 数量、年龄、普通编号 |
| `BIGINT` | 主键 ID、订单号 |
| `DECIMAL(p, s)` | 金额、精确小数 |
| `FLOAT`, `DOUBLE` | 允许误差的小数 |

金额优先用 `DECIMAL`，不要用 `FLOAT` 或 `DOUBLE`。

### 字符串类型

| 类型 | 用途 |
| --- | --- |
| `CHAR(n)` | 固定长度编码 |
| `VARCHAR(n)` | 用户名、标题、手机号 |
| `TEXT` | 文章内容、备注 |
| `JSON` | 半结构化扩展字段 |

### 日期时间类型

| 类型 | 用途 |
| --- | --- |
| `DATE` | 日期 |
| `TIME` | 时间 |
| `DATETIME` | 日期时间，常用于业务时间 |
| `TIMESTAMP` | 时间戳，会受时区影响 |

### 创建时间

```sql
`created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
```

### 更新时间

```sql
`updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
```

## 约束

| 约束 | 关键字 | 作用 |
| --- | --- | --- |
| 主键 | `PRIMARY KEY` | 唯一标识一行 |
| 自增 | `AUTO_INCREMENT` | 自动生成递增值 |
| 非空 | `NOT NULL` | 字段不能为空 |
| 唯一 | `UNIQUE` | 字段值不能重复 |
| 默认值 | `DEFAULT` | 未指定时使用默认值 |
| 检查 | `CHECK` | 限制字段取值范围 |
| 外键 | `FOREIGN KEY` | 建立表之间的关联 |

### 外键写法

```sql
ALTER TABLE `employee`
ADD CONSTRAINT `fk_employee_department`
FOREIGN KEY (`dept_id`) REFERENCES `department`(`id`);
```

### 删除外键

```sql
ALTER TABLE `employee` DROP FOREIGN KEY `fk_employee_department`;
```

外键能保证关系正确，但会增加写入和维护成本。小项目可以用，业务复杂时也常由应用层保证关系。

### 批量插入


### 删除数据

```sql
DELETE FROM `user`
```


## DQL：查询 { #dql查询 }

### 查询指定字段

```sql
SELECT `id`, `username`, `age`
FROM `user`;
```

### 查询全部字段

```sql
SELECT *
FROM `user`;
```

临时排查可以用 `SELECT *`，正式代码尽量写明确字段。

### 字段别名

```sql
SELECT `username` AS `name`
FROM `user`;
```

### 去重

```sql
SELECT DISTINCT `status`
FROM `user`;
```

### 等值条件

```sql
SELECT *
FROM `user`
WHERE `id` = 1;
```

### 范围条件

```sql
SELECT *
FROM `user`
WHERE `age` BETWEEN 18 AND 30;
```

### 多选一

```sql
SELECT *
FROM `user`
WHERE `status` IN (1, 2);
```

### 模糊匹配

```sql
SELECT *
FROM `user`
WHERE `username` LIKE 'J%';
```

### 判断为空

```sql
SELECT *
FROM `user`
WHERE `email` IS NULL;
```

### 判断非空

```sql
SELECT *
FROM `user`
WHERE `email` IS NOT NULL;
```

`NULL` 不能用 `= NULL` 判断。

### 统计数量

```sql
SELECT COUNT(*)
FROM `user`;
```

### 求平均值

```sql
SELECT AVG(`age`)
FROM `user`
WHERE `status` = 1;
```

### 分组统计

```sql
SELECT `status`, COUNT(*) AS `user_count`
FROM `user`
GROUP BY `status`;
```

### 分组后筛选

```sql
SELECT `status`, COUNT(*) AS `user_count`
FROM `user`
GROUP BY `status`
HAVING `user_count` >= 10;
```

`WHERE` 在分组前过滤行，`HAVING` 在分组后过滤聚合结果。

### 排序

```sql
SELECT *
FROM `user`
ORDER BY `age` ASC;
```

### 多字段排序

```sql
SELECT *
FROM `user`
ORDER BY `age` ASC, `created_at` DESC;
```

### 分页第一页

```sql
SELECT *
FROM `user`
LIMIT 0, 10;
```

### 分页第二页

```sql
SELECT *
FROM `user`
LIMIT 10, 10;
```

分页起始索引：

```text
起始索引 = (页码 - 1) * 每页条数
```

### 查询执行顺序

```text
FROM -> WHERE -> GROUP BY -> HAVING -> SELECT -> ORDER BY -> LIMIT
```

| 关系 | 例子 | 设计方式 |
| --- | --- | --- |
| 一对多 | 部门和员工 | 在“多”的一方加外键 |

## 多表查询 { #多表查询 }

### 内连接

```sql
SELECT `e`.`name` AS `employee_name`, `d`.`name` AS `department_name`
FROM `employee` AS `e`
INNER JOIN `department` AS `d` ON `e`.`dept_id` = `d`.`id`;
```

内连接只查两张表都能匹配上的数据。

### 左连接

```sql
SELECT `e`.`name` AS `employee_name`, `d`.`name` AS `department_name`
FROM `employee` AS `e`
LEFT JOIN `department` AS `d` ON `e`.`dept_id` = `d`.`id`;
```

左连接保留左表所有数据，右表匹配不到时显示 `NULL`。

### 查没有部门的员工

```sql
SELECT `e`.*
FROM `employee` AS `e`
LEFT JOIN `department` AS `d` ON `e`.`dept_id` = `d`.`id`
WHERE `d`.`id` IS NULL;
```

### 自连接

```sql
SELECT `e`.`name` AS `employee_name`, `m`.`name` AS `manager_name`
FROM `employee` AS `e`
LEFT JOIN `employee` AS `m` ON `e`.`manager_id` = `m`.`id`;
```

### UNION ALL

```sql
SELECT `username` FROM `user` WHERE `status` = 1
UNION ALL
SELECT `username` FROM `user_archive` WHERE `status` = 1;
```

`UNION` 会去重，`UNION ALL` 不去重，通常更快。

### 子查询

```sql
SELECT *
FROM `employee`
WHERE `salary` > (SELECT AVG(`salary`) FROM `employee`);
```

能用清晰 `JOIN` 表达时，通常优先考虑 `JOIN`。

## 事务 { #事务 }

### 开启事务

```sql
START TRANSACTION;
```

### 提交事务

```sql
COMMIT;
```

### 回滚事务

```sql
ROLLBACK;
```

### 转账示例

```sql
START TRANSACTION;
```

```sql
UPDATE `account`
SET `balance` = `balance` - 100
WHERE `id` = 1;
```

```sql
UPDATE `account`
SET `balance` = `balance` + 100
WHERE `id` = 2;
```

```sql
COMMIT;
```

事务四大特性：

| 特性 | 含义 |
| --- | --- |
| 原子性 | 要么全成功，要么全失败 |
| 一致性 | 事务前后数据规则正确 |
| 隔离性 | 并发事务之间尽量互不干扰 |
| 持久性 | 提交后的结果会持久保存 |

### 查看隔离级别

```sql
SELECT @@TRANSACTION_ISOLATION;
```

### 设置当前会话隔离级别

```sql
SET SESSION TRANSACTION ISOLATION LEVEL READ COMMITTED;
```

MySQL InnoDB 默认隔离级别通常是 `REPEATABLE READ`。

## 索引基础 { #索引基础 }

索引可以加快查询，但会占空间，并降低写入时的维护速度。

### 创建普通索引

```sql
CREATE INDEX `idx_user_status`
ON `user` (`status`);
```

### 创建联合索引

```sql
CREATE INDEX `idx_user_status_age`
ON `user` (`status`, `age`);
```

### 查看索引

```sql
SHOW INDEX FROM `user`;
```

### 删除索引

```sql
DROP INDEX `idx_user_status`
ON `user`;
```

### 最左前缀

如果索引是：

```sql
CREATE INDEX `idx_user_status_age`
ON `user` (`status`, `age`);
```

容易用上索引：

```sql
SELECT *
FROM `user`
WHERE `status` = 1;
```

也容易用上索引：

```sql
SELECT *
FROM `user`
WHERE `status` = 1 AND `age` > 18;
```

不容易充分使用这个联合索引：

```sql
SELECT *
FROM `user`
WHERE `age` > 18;
```

联合索引从最左边字段开始连续使用。

### 容易导致索引失效

对字段做函数计算：

```sql
SELECT *
FROM `user`
WHERE SUBSTRING(`username`, 1, 1) = 'J';
```

左模糊匹配：

```sql
SELECT *
FROM `user`
WHERE `username` LIKE '%ack';
```

字符串字段没有加引号，可能发生隐式类型转换：

```sql
SELECT *
FROM `user`
WHERE `phone` = 13800138000;
```

### 查看执行计划

```sql
EXPLAIN
SELECT *
FROM `user`
WHERE `status` = 1
ORDER BY `created_at` DESC;
```

重点先看：

| 字段 | 关注点 |
| --- | --- |
| `type` | 访问类型，`ALL` 通常表示全表扫描 |
| `key` | 实际使用的索引 |
| `rows` | 预计扫描行数，越少越好 |
| `Extra` | 额外信息，如 `Using index`, `Using filesort` |

## 用户和权限 { #用户和权限 }

### 进入 mysql 系统库

```sql
USE `mysql`;
```

### 查看用户

```sql
SELECT `user`, `host`
FROM `user`;
```

### 创建本机用户

```sql
CREATE USER 'test'@'localhost' IDENTIFIED BY '123456';
```

### 创建远程用户

```sql
CREATE USER 'test'@'%' IDENTIFIED BY '123456';
```

### 修改密码

```sql
ALTER USER 'test'@'localhost' IDENTIFIED BY '1234';
```

### 删除用户

```sql
DROP USER 'test'@'localhost';
```

### 查看权限

```sql
SHOW GRANTS FOR 'test'@'localhost';
```

### 授权

```sql
GRANT SELECT, INSERT, UPDATE
ON `blog`.*
TO 'test'@'localhost';
```

### 撤销权限

```sql
REVOKE UPDATE
ON `blog`.*
FROM 'test'@'localhost';
```

授权时遵循最小权限原则，只给完成任务所需的权限。


### 查看数据库大小

```sql
SELECT
  `table_schema` AS `database_name`,
  ROUND(SUM(`data_length` + `index_length`) / 1024 / 1024, 2) AS `size_mb`
FROM `information_schema`.`tables`
GROUP BY `table_schema`
ORDER BY `size_mb` DESC;
```
