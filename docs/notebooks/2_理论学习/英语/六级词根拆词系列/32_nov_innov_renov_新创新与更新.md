# 32 nov / innov / renov：新、创新与更新

## 核心词根

- <span style="color:#dc2626;font-weight:700">nov</span>：新。

## nov：新

| 单词 | 彩色拆词 | 构词逻辑 | 六级常用义 |
| --- | --- | --- | --- |
| novel | <span style="color:#dc2626;font-weight:700">nov</span> + <span style="color:#16a34a;font-weight:700">-el</span> | 新奇的故事形式，后来指小说 | 小说；新颖的 |
| novelty | <span style="color:#dc2626;font-weight:700">nov</span> + <span style="color:#16a34a;font-weight:700">-elty</span> | 新这个性质 | 新奇，新颖事物 |
| novice | <span style="color:#dc2626;font-weight:700">nov</span> + <span style="color:#16a34a;font-weight:700">-ice</span> | 新进入某领域的人 | 新手 |
| innovate | <span style="color:#2563eb;font-weight:700">in</span> + <span style="color:#dc2626;font-weight:700">nov</span> + <span style="color:#16a34a;font-weight:700">-ate</span> | 把新东西放进去 | 创新 |
| innovation | <span style="color:#2563eb;font-weight:700">in</span> + <span style="color:#dc2626;font-weight:700">nov</span> + <span style="color:#16a34a;font-weight:700">-ation</span> | 引入新东西的行为或成果 | 创新 |
| innovative | <span style="color:#2563eb;font-weight:700">in</span> + <span style="color:#dc2626;font-weight:700">nov</span> + <span style="color:#16a34a;font-weight:700">-ative</span> | 能创造新东西的 | 创新的 |
| renovate | <span style="color:#2563eb;font-weight:700">re</span> + <span style="color:#dc2626;font-weight:700">nov</span> + <span style="color:#16a34a;font-weight:700">-ate</span> | 重新变新 | 翻新，修复 |
| renovation | <span style="color:#2563eb;font-weight:700">re</span> + <span style="color:#dc2626;font-weight:700">nov</span> + <span style="color:#16a34a;font-weight:700">-ation</span> | 让旧物重新变新 | 翻新，整修 |
| renew | <span style="color:#2563eb;font-weight:700">re</span> + <span style="color:#dc2626;font-weight:700">new</span> | 重新变新 | 更新；续订 |
| renewable | <span style="color:#2563eb;font-weight:700">re</span> + <span style="color:#dc2626;font-weight:700">new</span> + <span style="color:#16a34a;font-weight:700">-able</span> | 能重新生成的 | 可再生的 |

## 六级常见搭配

| 搭配 | 记忆 |
| --- | --- |
| technological innovation | 技术里放进新东西 |
| renewable energy | 能不断重新生成的能源 |
| an innovative approach | 有新方法的 approach |
| renovate old buildings | 让旧建筑重新变新 |

## 词义延伸主线

`nov` 是“新”。小说 `novel` 原来有“新奇故事”的感觉；创新是把新东西放进系统；翻新是让旧东西重新变新。
