# 33 vers / vert / vari：转向、变化与多样

## 核心词根

- <span style="color:#dc2626;font-weight:700">vers / vert</span>：转。
- <span style="color:#dc2626;font-weight:700">vari</span>：变化，不同。

## 词义延伸主线

`vers / vert` 是“转”：转成别的状态是 convert，转移注意力是 divert，转到相反方向是 reverse，双方立场反着转就是 controversy。`vari` 是“变”，变化多了就是 variety 和 diversity。
