# 18 ten / tend / tent：伸展、倾向与紧张

## 核心词根

- <span style="color:#dc2626;font-weight:700">ten / tend / tent</span>：伸展，拉紧，倾向。

## 词义延伸主线

`tend` 是伸向：注意力伸过去是 attention，范围伸出去是 extension，内心伸向目标是 intention。`ten / tent` 是拉紧：拉得紧是 tension，强烈到拉满是 intense，多方一起拉就是 contention。
