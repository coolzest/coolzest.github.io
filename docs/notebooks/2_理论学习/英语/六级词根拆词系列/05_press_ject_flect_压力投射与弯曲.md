# 05 press / ject / flect：压、投射与弯曲

## 核心词根

- <span style="color:#dc2626;font-weight:700">press</span>：压。
- <span style="color:#dc2626;font-weight:700">ject</span>：投，扔。
- <span style="color:#dc2626;font-weight:700">flect / flex</span>：弯，折。

## 词义延伸主线

`press` 的词都和压力有关：往外压是表达，往心里压是印象，往下压是沮丧，压住不放是抑制。`ject` 是投：投向未来是项目，扔回去是拒绝，投进去是注入，放在面前就是客观对象。`flect` 是弯：弯回来是反映，能弯就是灵活，弯走就是转移。
