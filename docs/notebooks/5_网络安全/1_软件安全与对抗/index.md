# 软件安全与对抗

> 这一组笔记按“程序怎么存在、内存怎么组织、漏洞怎么发生”的顺序写。先把可执行文件、虚拟内存、栈、堆讲清楚，再把常见漏洞和防护机制串起来。

## 学习路线

```mermaid
flowchart LR
    A[可执行文件] --> B[虚拟内存]
    B --> C[栈]
    C --> D[堆]
    D --> E[漏洞与防护]
```

1. 先看可执行文件：程序在磁盘上如何组织，操作系统如何装载它。
2. 再看虚拟内存：地址、页表、权限、ASLR 和进程隔离是什么。
3. 接着看栈：函数调用、返回地址、局部变量和栈溢出。
4. 然后看堆：动态内存、堆块、释放、复用和生命周期错误。
5. 最后串起来：常见漏洞如何形成，防护机制分别挡在哪里。
