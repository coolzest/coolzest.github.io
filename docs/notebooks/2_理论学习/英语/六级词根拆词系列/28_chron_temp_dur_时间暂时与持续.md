# 28 chron / temp / dur：时间、暂时与持续

## 核心词根

- <span style="color:#dc2626;font-weight:700">chron</span>：时间。
- <span style="color:#dc2626;font-weight:700">temp</span>：时间，时机。
- <span style="color:#dc2626;font-weight:700">dur</span>：持续，坚硬。

## chron：时间

| 单词 | 彩色拆词 | 构词逻辑 | 六级常用义 |
| --- | --- | --- | --- |
| chronic | <span style="color:#dc2626;font-weight:700">chron</span> + <span style="color:#16a34a;font-weight:700">-ic</span> | 时间拖得很长的 | 慢性的；长期的 |
| chronology | <span style="color:#dc2626;font-weight:700">chron</span> + <span style="color:#7c3aed;font-weight:700">logy</span> | 按时间系统记录 | 年代学；时间顺序 |
| chronological | <span style="color:#dc2626;font-weight:700">chron</span> + <span style="color:#7c3aed;font-weight:700">log</span> + <span style="color:#16a34a;font-weight:700">-ical</span> | 按时间顺序的 | 按年代顺序的 |
| synchronize | <span style="color:#2563eb;font-weight:700">syn</span> + <span style="color:#dc2626;font-weight:700">chron</span> + <span style="color:#16a34a;font-weight:700">-ize</span> | `syn` 一起 + 时间：让时间一致 | 同步 |
| simultaneous | <span style="color:#7c3aed;font-weight:700">simul</span> + <span style="color:#16a34a;font-weight:700">-taneous</span> | `simul` 同时，不是 chron，但同属时间词 | 同时的 |
| anachronism | <span style="color:#2563eb;font-weight:700">ana</span> + <span style="color:#dc2626;font-weight:700">chron</span> + <span style="color:#16a34a;font-weight:700">-ism</span> | 时间错位的东西 | 时代错误 |

| 单词 | 彩色拆词 | 构词逻辑 | 六级常用义 |
| --- | --- | --- | --- |
| temporary | <span style="color:#dc2626;font-weight:700">temp</span> + <span style="color:#16a34a;font-weight:700">-orary</span> | 只存在一段时间的 | 暂时的 |

## dur：持续，坚硬

| 单词 | 彩色拆词 | 构词逻辑 | 六级常用义 |
| --- | --- | --- | --- |
| during | <span style="color:#dc2626;font-weight:700">dur</span> + <span style="color:#16a34a;font-weight:700">-ing</span> | 在持续的一段时间内 | 在...期间 |
| duration | <span style="color:#dc2626;font-weight:700">dur</span> + <span style="color:#16a34a;font-weight:700">-ation</span> | 持续的时间长度 | 持续时间 |
| durable | <span style="color:#dc2626;font-weight:700">dur</span> + <span style="color:#16a34a;font-weight:700">-able</span> | 能持续使用的 | 耐用的 |
| endurance | <span style="color:#2563eb;font-weight:700">en/in</span> + <span style="color:#dc2626;font-weight:700">dur</span> + <span style="color:#16a34a;font-weight:700">-ance</span> | 在困难中持续承受 | 忍耐力，耐久力 |
| endure | <span style="color:#2563eb;font-weight:700">en/in</span> + <span style="color:#dc2626;font-weight:700">dur</span> + <span style="color:#16a34a;font-weight:700">-e</span> | 持续承受 | 忍受，持续 |
| permanent | <span style="color:#2563eb;font-weight:700">per</span> + <span style="color:#7c3aed;font-weight:700">man</span> + <span style="color:#16a34a;font-weight:700">-ent</span> | 一直停留，不是 dur，但常和 temporary 对比 | 永久的 |

## 词义延伸主线

`chron` 是时间轴，按时间顺序就是 chronological；`temp` 是时间段或时机，temporary 是暂时，contemporary 是同一时代；`dur` 是持续，duration 是持续时间，durable 是能持续用。
