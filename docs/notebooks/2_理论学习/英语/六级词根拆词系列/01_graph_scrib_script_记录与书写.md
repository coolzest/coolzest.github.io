# 01 graph / scrib / script：记录与书写

## 核心词根

- <span style="color:#dc2626;font-weight:700">graph</span>：写、画、记录。`graph` 单独作名词时是图表，因为图表就是“把信息画下来、记录下来”。
- <span style="color:#dc2626;font-weight:700">scrib / script</span>：写。`script` 更偏“写好的文本、稿子、文字系统”。

## 词义延伸主线

`graph` 这艘船的核心货物是“记录”。用光记录是照片，用自己记录是签名，用生命记录是传记，用地球记录是地理学，用书记录是书目。`scrib / script` 更偏文字本身：写下来、规定下来、转写下来、订阅时签下来。
