# 14 voc / phon / son：声音、呼喊与声响

## 核心词根

- <span style="color:#dc2626;font-weight:700">voc / vok</span>：声音，呼喊。
- <span style="color:#dc2626;font-weight:700">phon</span>：声音。
- <span style="color:#dc2626;font-weight:700">son</span>：声音，声响。

## 词义延伸主线

声音被组织成词汇是 vocabulary，替某个观点发声是 advocate，声音从远处来是 telephone，多种声音合在一起是 symphony，声音回响到心里就是 resonance。
