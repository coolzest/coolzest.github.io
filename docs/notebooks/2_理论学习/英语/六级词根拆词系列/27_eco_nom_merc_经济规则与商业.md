# 27 eco / nom / merc：经济、规则与商业

## 核心词根

- <span style="color:#dc2626;font-weight:700">eco</span>：家园，环境，经济。
- <span style="color:#dc2626;font-weight:700">nom</span>：管理，规则，分配。
- <span style="color:#dc2626;font-weight:700">merc / market</span>：交易，商业。

## 词义延伸主线

`eco` 最早像“家园”，研究家园环境是 ecology，管理家园资源是 economy。`nom` 是规则和管理，自我管理是 autonomy。`merc` 是交易，商业、商品、市场都从交换行为延伸而来。
