# 04 回归与分类

> 回归和分类是机器学习最基础的两类任务。一个预测“多少”，一个判断“是哪类”。

## 一句话

回归预测数值，分类预测类别。

| 任务 | 输出 | 例子 |
| --- | --- | --- |
| 回归 | 连续数值 | 房价、温度、销量 |
| 分类 | 类别标签 | 垃圾邮件/正常邮件，猫/狗 |

```text
回归：输入房屋信息 -> 预测 320 万
分类：输入邮件内容 -> 判断 垃圾邮件
```

## 回归：预测一个数

最容易理解的回归是线性回归。

```text
房价 = 面积 × 权重 + 偏置
```

图像上就是找一条尽量贴近数据点的线：

```text
价格
 ^
 |             *
 |          *
 |       *
 |    *
 | *
 +----------------> 面积
```

真实任务会有多个特征：

```text
房价 = 面积×w1 + 楼层×w2 + 年份×w3 + 城市×w4 + b
```

这里的 `w` 是权重，`b` 是偏置。训练就是找到一组更合适的 `w` 和 `b`。

## 回归怎么看好坏

| 指标 | 含义 | 越小越好 |
| --- | --- | --- |
| MAE | 平均绝对误差 | 是 |
| MSE | 平均平方误差 | 是 |
| RMSE | MSE 开根号 | 是 |

例子：

```text
真实价格：300 万
预测价格：320 万
误差：20 万
```

回归指标关注的是：预测值离真实值有多远。

## 分类：判断是哪一类

分类模型输出的是类别。

```text
邮件内容 -> 模型 -> 垃圾邮件 / 正常邮件
```

有些模型会先输出概率：

```text
垃圾邮件概率：0.92
正常邮件概率：0.08
```

然后选择概率最大的类别。

## 二分类和多分类

| 类型 | 说明 | 例子 |
| --- | --- | --- |
| 二分类 | 只有两个类别 | 是/否，正常/异常 |
| 多分类 | 多个类别选一个 | 猫/狗/鸟/鱼 |
| 多标签分类 | 一个样本可以有多个标签 | 一篇文章同时属于科技、教育 |

先分清分类类型，评价指标才不会用错。

## 分类怎么看好坏

最简单的是准确率：

```text
准确率 = 预测正确的数量 / 总数量
```

但准确率不总是可靠。比如 1000 封邮件里只有 10 封垃圾邮件，模型全猜“正常”，准确率也有 99%，但它完全没抓到垃圾邮件。

这时要看：

| 指标 | 关心什么 |
| --- | --- |
| 精确率 Precision | 预测为正的里面，有多少是真的 |
| 召回率 Recall | 真正为正的里面，找回了多少 |
| F1 | 精确率和召回率的综合 |

## 混淆矩阵

分类结果可以用一个小表看清楚。

```text
                预测垃圾    预测正常
真实垃圾          TP          FN
真实正常          FP          TN
```

| 名称 | 含义 |
| --- | --- |
| TP | 真的垃圾，也预测垃圾 |
| FP | 正常邮件，被误判垃圾 |
| FN | 垃圾邮件，被漏掉 |
| TN | 真的正常，也预测正常 |

安全、医疗等场景里，漏报和误报的代价不同，所以不能只看准确率。

## 常见模型

| 模型 | 直觉 |
| --- | --- |
| 线性回归 | 找一条线预测数值 |
| 逻辑回归 | 用一条边界做分类 |
| 决策树 | 像一串 if-else 判断 |
| 随机森林 | 很多棵树投票 |
| 神经网络 | 多层可学习函数组合 |

## 小结

- 回归预测数值，分类预测类别。
- 线性回归的核心是找权重和偏置。
- 分类常输出概率，再转成类别。
- 数据不均衡时，准确率可能骗人。
- 精确率、召回率、F1 能更细地看分类效果。
