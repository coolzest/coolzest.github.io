# 08 log / lingu / ver：语言、逻辑与真实

## 核心词根

- <span style="color:#dc2626;font-weight:700">log / logy</span>：话语，逻辑，学科。一个领域被系统讲清楚，就成了某某学。
- <span style="color:#dc2626;font-weight:700">lingu</span>：语言，舌头。
- <span style="color:#dc2626;font-weight:700">ver</span>：真实。

## 词义延伸主线

`log` 从话语发展到逻辑，再发展成系统学科；`lingu` 抓住语言本身，双语就是两个语言，多语就是多个语言；`ver` 抓住真实，核实是让事情变得可确认，裁决是说出真实判断。
