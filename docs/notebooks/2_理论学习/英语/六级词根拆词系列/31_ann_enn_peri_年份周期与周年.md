# 31 ann / enn / peri：年份、周期与周年

## 核心词根

- <span style="color:#dc2626;font-weight:700">ann / enn</span>：年。
- <span style="color:#dc2626;font-weight:700">peri</span>：周围，周期。

## ann / enn：年

| 单词 | 彩色拆词 | 构词逻辑 | 六级常用义 |
| --- | --- | --- | --- |
| annual | <span style="color:#dc2626;font-weight:700">ann</span> + <span style="color:#16a34a;font-weight:700">-ual</span> | 按“年”发生的 | 每年的，年度的 |
| annually | <span style="color:#dc2626;font-weight:700">ann</span> + <span style="color:#16a34a;font-weight:700">-ually</span> | 以年为单位地 | 每年 |
| anniversary | <span style="color:#dc2626;font-weight:700">ann</span> + <span style="color:#7c3aed;font-weight:700">vers</span> + <span style="color:#16a34a;font-weight:700">-ary</span> | `ann` 年 + `vers` 转：一年转回来一次 | 周年纪念日 |
| biannual | <span style="color:#2563eb;font-weight:700">bi</span> + <span style="color:#dc2626;font-weight:700">ann</span> + <span style="color:#16a34a;font-weight:700">-ual</span> | `bi` 两 + 年：一年两次或两年一次，语境决定 | 一年两次的；两年一次的 |
| perennial | <span style="color:#2563eb;font-weight:700">per</span> + <span style="color:#dc2626;font-weight:700">enn</span> + <span style="color:#16a34a;font-weight:700">-ial</span> | `per` 贯穿 + 年：多年持续 | 长期存在的；多年生的 |
| millennium | <span style="color:#7c3aed;font-weight:700">milli</span> + <span style="color:#dc2626;font-weight:700">enn</span> + <span style="color:#16a34a;font-weight:700">-ium</span> | `milli` 千 + 年 | 千年 |

## peri：周围，周期

| 单词 | 彩色拆词 | 构词逻辑 | 六级常用义 |
| --- | --- | --- | --- |
| period | <span style="color:#dc2626;font-weight:700">peri</span> + <span style="color:#16a34a;font-weight:700">-od</span> | 绕完一圈形成的一段时间 | 时期，周期 |
| periodic | <span style="color:#dc2626;font-weight:700">peri</span> + <span style="color:#16a34a;font-weight:700">-odic</span> | 按周期绕回来 | 周期性的 |
| perimeter | <span style="color:#dc2626;font-weight:700">peri</span> + <span style="color:#7c3aed;font-weight:700">meter</span> | 周围 + 测量：量出来的外圈 | 周长，边界 |
| peripheral | <span style="color:#dc2626;font-weight:700">peri</span> + <span style="color:#7c3aed;font-weight:700">pher</span> + <span style="color:#16a34a;font-weight:700">-al</span> | 在中心周围的 | 外围的，次要的 |

## 词义延伸主线

`ann` 抓住“年”，年度报告就是 annual report；`anniversary` 是一年转回同一天。`peri` 抓住“绕圈”，绕一圈是 period，绕外圈量出来是 perimeter。
