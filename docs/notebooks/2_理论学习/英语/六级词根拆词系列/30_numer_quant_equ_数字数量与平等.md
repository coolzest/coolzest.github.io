# 30 numer / quant / equ：数字、数量与平等

## 核心词根

- <span style="color:#dc2626;font-weight:700">numer</span>：数字，数。
- <span style="color:#dc2626;font-weight:700">quant</span>：数量，多少。
- <span style="color:#dc2626;font-weight:700">equ</span>：相等，平衡。

## 词义延伸主线

`numer` 是具体数字，numerous 是数量多；`quant` 是“多少”，quantify 是量化，quality 则是“什么性质”，别和 quantity 混。`equ` 是相等，平等是 equality，价值相等是 equivalent，达到相等要求就是 adequate。
