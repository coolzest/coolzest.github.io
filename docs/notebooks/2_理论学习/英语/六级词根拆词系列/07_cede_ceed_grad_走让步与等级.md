# 07 cede / ceed / grad：走、让步与等级

## 核心词根

- <span style="color:#dc2626;font-weight:700">cede / ceed / cess</span>：走，让步，前进。不同拼写是同一组变体。
- <span style="color:#dc2626;font-weight:700">grad / gress</span>：走，台阶，等级。`grad` 更像一步一步上台阶。

## 词义延伸主线

`cede / ceed / cess` 是走：向前走是继续，走过头是过度，往回走是衰退，退一步是让步，走近资源就是 access。`grad / gress` 是台阶式地走：一步步是 gradual，走完学业等级是 graduate，往上是 upgrade，往下是 degrade，向前是 progress。
