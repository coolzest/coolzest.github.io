# 24 rupt / frag / fract：破裂、碎片与脆弱

## 核心词根

- <span style="color:#dc2626;font-weight:700">rupt</span>：破裂。
- <span style="color:#dc2626;font-weight:700">frag / fract</span>：打碎，碎片。

## 词义延伸主线

`rupt` 是破开：火山向外破开是 erupt，中间破开是 interrupt，秩序被打破是 disrupt，道德系统破坏是 corrupt。`frag / fract` 是碎：碎片是 fragment，易碎是 fragile，一小块是 fraction。
