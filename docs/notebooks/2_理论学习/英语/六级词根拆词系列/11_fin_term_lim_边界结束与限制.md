# 11 fin / term / lim：边界、结束与限制

## 核心词根

- <span style="color:#dc2626;font-weight:700">fin</span>：结束，边界。
- <span style="color:#dc2626;font-weight:700">term</span>：界限，期限，术语。
- <span style="color:#dc2626;font-weight:700">lim / limit</span>：门槛，边界，限制。

## 词义延伸主线

`fin` 是边界和结束，划边界就是 define，有边界就是 finite，没边界就是 infinite；`term` 是时间或意义的界限，所以是学期、术语、期限；`lim` 是门槛和限制，清出边界外就是 eliminate，正式门槛前就是 preliminary。
