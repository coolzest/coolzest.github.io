# 03 tele / trans / port：远程、穿越与搬运

## 核心词根

- <span style="color:#dc2626;font-weight:700">tele</span>：远，远程。
- <span style="color:#dc2626;font-weight:700">trans</span>：穿过，转移，改变到另一边。
- <span style="color:#dc2626;font-weight:700">port</span>：搬运，携带。

| television | <span style="color:#dc2626;font-weight:700">tele</span> + <span style="color:#7c3aed;font-weight:700">vis</span> + <span style="color:#16a34a;font-weight:700">-ion</span> | 远程 + 看：远处画面被看见 | 电视 |
| telescope | <span style="color:#dc2626;font-weight:700">tele</span> + <span style="color:#7c3aed;font-weight:700">scope</span> | 远处 + 看：看远处的工具 | 望远镜 |
| telegraph | <span style="color:#dc2626;font-weight:700">tele</span> + <span style="color:#7c3aed;font-weight:700">graph</span> | 远程 + 记录：远距离传送文字记录 | 电报 |

## 词义延伸主线

远处传声音是电话，远处传图像是电视，远处传记录是电报；`trans` 让东西“过界”，于是有转移、转型、传播、翻译；`port` 负责搬运，搬进来是进口，搬出去是出口，从下面托住就是支持。
