# 21 mov / mot / mob：移动、动机与流动

- <span style="color:#dc2626;font-weight:700">mov / mot / mob</span>：移动。

## 词义延伸主线

`mov / mot / mob` 都围绕“动”。移动物体是 move，推动事情向前是 promote，推动人行动的是 motivation，情绪是从内心动出来的东西，社会流动性就是 mobility。
